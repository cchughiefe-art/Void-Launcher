# Void Launcher 2.0

Void Launcher 2.0 is rebuilt on Android Launcher3 and Lawnchair 16 under their Apache 2.0 licenses.

The application ID remains `com.voidlauncher.app` for update compatibility. Android 15+ system Private Space, widgets, workspace pages, folders, drag and drop, shortcuts, notification dots, icon packs, search, backup and profile-aware app loading are provided by the production launcher foundation.

Run **Build signed Void Launcher APK** in GitHub Actions to create the signed APK using the existing Void repository secrets.
